# PHYSICA — さわって学ぶ、物理実験室

高校物理の5つの基本実験と、複数物体・連成運動の自由実験室を、ドラッグ・数式・時系列グラフで学べる日本語Webアプリです。物理計算は **Pythonの独立モジュール**、画面はReact + TypeScript + Viteで実装しています。通常は、そのPythonコードを **Pyodide（WebAssembly）のWeb Worker内** で実行します。ブラウザだけで計算が完結し、Pythonサーバーの契約・起動や外部APIの設定は不要です。

## 起動

必要環境：Node.js 22.12以上推奨、npm。通常の開発・ビルド・公開にPythonのインストールは不要です。Node 18.19でもビルドを確認しています。

```bash
npm ci
npm run dev
```

ブラウザで **http://127.0.0.1:5173/** を開きます。Viteだけで起動します。終了はCtrl+C。ポートが使用中の場合は、そのポートを使っているプロセスを先に停止してください。

ビルドした静的サイトを確認する場合：

```bash
npm run build
npm start
```

**http://127.0.0.1:8000/** を開きます。ローカルでは127.0.0.1だけで待ち受けます。`npm start`はVite Previewによる確認用です。公開先では`dist/`を静的配信します。

ビルド時にPythonランタイムと既存の物理計算コードを`dist/physics-runtime/`へ同梱します。初回の計算準備では約13 MiBのファイルを同じサイトから読み込みます。2回目以降はブラウザのHTTPキャッシュを利用でき、CDNや外部の計算サービスへ接続しません。フォントも同梱しています。ファイルの取得後はWeb Workerが計算し、画面の操作とは独立して動作します。ページ全体をオフラインで再起動するPWA機能はありません。

## Vercelへの公開

1. VercelでこのGitHubリポジトリをインポートします。Root Directoryはリポジトリのルートにします。
2. Framework Presetを **Vite** にします。`vercel.json`に記載したInstall Command=`npm ci`、Build Command=`npm run build`、Output Directory=`dist`を利用します。以前の上書き設定があれば、この値に合わせてください。
3. 通常運用では環境変数は不要です。`VITE_PHYSICS_MODE`は設定せず、既に`http`を設定している場合は削除します。
4. Deployを実行します。設定や環境変数を変更した場合は再デプロイしてください。

通常の画面は静的ファイルの配信とブラウザ内の計算だけで動作します。別のサーバーや有料の計算サービスを追加する必要はありません。Vercelの利用枠は契約プランに従います。

### 互換HTTP API（任意）

従来のAPIを直接呼びたい場合に備え、`api/physics.py`をVercel Python Functionとして用意しています。Python 3.12・標準ライブラリのみで、追加の認証設定や外部サービスは不要です。通常の画面からは呼び出しません。`vercel.json`が`/api/*`をこのFunctionへ転送します。

```bash
curl https://YOUR-PROJECT.vercel.app/api/health
# {"status":"ok","engine":"Python / analytical + Verlet","hz":120}
curl https://YOUR-PROJECT.vercel.app/api/simulate \
  -H 'Content-Type: application/json' \
  -d '{"kind":"linear","params":{"v0":2,"a":1}}'
```

正常時は200、不正な入力は400、存在しないAPIは404、対応しないHTTPメソッドは405をJSONで返します。大きな結果はgzip対応クライアントへ圧縮して送り、送信サイズが4 MBを超える場合は413のJSONエラーを返します。大規模な自由実験にはブラウザ内計算を使ってください。

ローカルでHTTP APIを使う場合に限り、Python 3.10以上が必要です。

```bash
# Python API（8000）とHTTPモードのVite（5173）を同時起動
npm run dev:server
# またはPython API・既存distの配信だけを起動
npm run serve:api
```

### 「Unexpected token 'T'」が発生していた原因

以前は画面が`/api/simulate`などへHTTPリクエストを送り、開発時だけViteのプロキシがローカルPythonサーバーへ転送していました。VercelにはそのPythonサーバーがなく、APIの応答が404のテキスト`The page could not be found`となり、これをJSONとして読む処理が失敗していました。

現在は通常の実験をブラウザ内で実行するため、HTTP APIの有無に依存しません。HTTPモードでもContent-Type・ステータス・JSON形式を検査し、問題を日本語で表示します。初回の計算準備に失敗する場合は、再デプロイ後のページを再読み込みし、開発者ツールのNetworkで`physics-runtime/`の`.mjs`・`.wasm`・`.zip`・JSONが200で取得できるか確認してください。

## 操作

- 左側から実験を選び、右側のスライダー・数値欄で条件を設定します。数値はEnterまたはフォーカスを外すと反映されます。範囲外の数値は上下限に補正し、空欄は元の値に戻します。
- **条件変更はすべて一時停止し、時刻0から再計算します。** 再生中の物体に外力を注入する操作ではありません。
- 物体をドラッグすると、離した位置を初期位置に設定します。ドラッグ中は移動先のガイドを表示します。
- 斜面の丸いハンドルで角度、放物運動の初速度矢印の丸い先端で初速と投射角を変更できます。初速度ハンドルは時刻0で表示します。投射は右上方向（0～90°）を対象とします。
- 再生・一時停止（スペースキーにも対応）、リセット、**1/120秒の1ステップ送り**、0.25～4倍速が使えます。数値入力中のスペースは再生操作になりません。
- 時刻スライダーで0～30秒を移動できます。30秒で実験を停止し、再び再生すると時刻0から開始します。画面外への移動による壁・反射は追加していません。
- 手のひらツールを選んで背景をドラッグすると視点移動、＋/−で拡大縮小、照準ボタンで現在の物体を中央に戻せます。
- 速度・加速度・力・軌跡・グリッドは個別に切り替えられます。矢印の物理量と大きさをラベルで表示し、換算スケールは実験エリアの下端に表示します。重力は青、垂直抗力は緑、摩擦は赤、速度は橙、加速度は紫です。力の換算倍率は質量に応じて変え、同一図内では統一します。
- グラフの位置・速度・加速度・エネルギー・運動量（衝突のみ）を切り替えられます。破線の縦線は現在時刻で、その先は解析解による予測です。複数系列は名前と線種でも区別します。
- 直感モードは短い説明、学習モードは力の分解と段階的な式、詳細モードは保存則と適用条件を表示します。
- 各実験に複数のプリセットがあります。初期条件の比較に利用できます。右下のCSV保存では0.1秒刻みの全30秒の予測データをSI単位付きで出力します。
- 右上の月・太陽ボタンでダークモードを切り替えます。選択はブラウザに保存されます。実験ガイドはEscで閉じられます。

## 実装した物理モデル

| 実験             | 解法・イベント処理                                                                     | 主な適用条件                                                                                          |
| ---------------- | -------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 等加速度直線運動 | x = x₀ + v₀t + at²/2、v = v₀ + at。反転時刻を解析的に計算                              | 水平・摩擦なし。F = ma の一定外力。重力は9.8 m/s²、重力と抗力は相殺                                   |
| 斜面             | 各滑走区間の等加速度解を接続。停止時刻を正確に求め、静止条件を再判定                   | 下向きを正のs。N = mg cosθ。静止時はf = −mg sinθかつ\|f\| ≤ μₛN。滑走時はf = −μₖN sgn(v)。0 ≤ μₖ ≤ μₛ |
| 放物運動         | x・yの解析解。y = 0の正の根で着地判定。最高点、飛距離、飛行時間を計算                  | 空気抵抗なし、一様重力。着地後は完全に静止するため着地時にエネルギーを失う                            |
| ばね振動         | ω = √(k/m) の厳密な調和振動解。初速度も含む                                            | 質量0の理想ばね、摩擦なし。x = 0が自然長。図は模式図でコイルや壁との接触は扱わない                    |
| 2物体の衝突      | 接触時刻を解析的に計算。運動量保存と反発係数から衝突後速度を求め、前後の等速運動を接続 | 外力なし、一次元、各物体幅1 m。瞬間衝突で、衝突瞬間の加速度は定義しない                               |

斜面は無限に続くものとして扱います。位置エネルギーの基準は斜面のs = 0、放物運動のy = 0、ばねの自然長です。負の位置エネルギーも正当な値です。摩擦は必ず運動と逆方向に仕事をし、静止時は常に最大静止摩擦が働くわけではありません。上り運動が止まったあとも、静止条件を満たさなければ下りへ転じます。

衝突ではe = 1で運動エネルギーを保存、e < 1では一部を失い、e = 0では同じ速度で移動します。接近しない条件では衝突しません。衝突瞬間の加速度・有限な衝撃力を表示する代わりに、速度の不連続で表現します。

## 計算・描画の分離

基本5実験の計算元は`server/physics.py`、連成運動は`server/multi/`です。同じPythonコードを、通常はPyodideのWeb Worker内、互換APIではPythonサーバー内で実行します。JavaScriptへの物理式の移植は行っていません。基本実験では時刻0から30秒まで、**1/120秒刻みの3601点を、それぞれ初期条件から直接解析的に計算**します。固定時間刻みは結果のサンプリング間隔であり、数値積分の刻みではありません。丸め以外の積分誤差は蓄積しません。

Reactは`requestAnimationFrame`で再生時刻を更新し、その時刻以下の最も近い計算済みフレームを参照します。表示時刻もその物理フレームの時刻です。FPS、再生速度、一時停止が物理解を変えることはありません。パラメータ変更時は古い要求を取り消して遅れて届いた結果を無視し、条件と一致する計算結果だけを描画します。

衝突・着地がフレーム間に起きる場合も、位置と速度は正確なイベント時刻を使って求めます。グラフは1/30秒刻みに間引いていますが、イベント時刻の左右極限を同じ時刻の2点として追加し、速度・エネルギーの跳びを正しい時刻に描きます。通常の曲線部分はこれらの標本間を直線で結びます。CSVは0.1秒刻みで、イベント直前・直後の専用点は含みません。

UIの条件と独立してPython計算モジュール側でも有限値、質量・ばね定数・重力の正値、摩擦係数、投射角、反発係数、初期位置の上下限を検証します。

## 自由実験・連成運動（追加機能）

基本実験の左メニューにある **「自由実験・連成運動」** を押すと、新しい実験室が開きます。開発サーバーでは `http://127.0.0.1:5173/#free`、ビルド後のローカル確認では `http://127.0.0.1:8000/#free` へ直接アクセスできます。起動方法は従来と同じです。

### 配置と編集

1. 左のパレットから、質点・ブロック・動く台・壁・床・斜面・固定支点・固定滑車をドラッグして配置します。パレットのクリックでも追加できます。ブロックは回転しない並進モデルです。
2. 「ばね」「糸」を選び、配置済みの第1端、第2端をクリックして接続します。ばねは物体・固定壁・固定支点へ接続できます。糸は対応する2物体と固定滑車を選びます。Escまたはキャンセルで接続操作を終了します。
3. 物体をクリックすると、右の編集欄で質量、初期位置・速度、支持先、寸法などを変更できます。台に支持される物体では静止・動摩擦係数も編集できます。接続は図または「接続と外力」の一覧から選び、ばね定数・自然長、糸の長さ・経由する滑車を編集します。
4. 外力は選択中の動く物体に追加します。外力矢印の丸い先端のドラッグで向きと大きさを設定でき、数値でFₓ・Fᵧも指定できます。どのモデルでも任意方向の外力が使えるわけではなく、経路と矛盾する外力は理由を表示して計算を止めます。
5. 条件の変更はすべて一時停止し、時刻0から再計算します。水平ガイドのドラッグでは高さを固定し、張った滑車系のドラッグでは相手の物体も動かして糸の長さを保ちます。初期位置を数値で変更して拘束と矛盾した場合は、修正するまで再生できません。
6. 再生・停止、1/120秒送り、0.25〜4倍速、時刻スライダーが使えます。重心追従、視点移動、拡大縮小、力の表示切替にも対応しています。実験時間は6・12・20・30秒から選べますが、対応範囲の境界が先に現れる場合はそこで打ち切ります。
7. 保存ボタンで実験構成をJSONに書き出し、読込ボタンで復元できます。読込時にもPython側で値・ID・接続を検証します。基本実験との切替中は現在のページ内で構成を保持しますが、ページの再読込やブラウザ終了後も残したい場合はJSONで保存してください。

| プリセット                   | 観察すること                           |
| ---------------------------- | -------------------------------------- |

| 台の上の物体（静止摩擦あり） | 共通加速度、必要な静止摩擦と限界       |
| 台の上の物体（滑りあり）     | 物体別の加速度、摩擦の作用反作用、散逸 |
| 2物体を1本のばねで接続       | 運動量と重心運動、振動数0の並進モード  |
| 2物体を3本のばねで接続       | 2つの固有振動数、同位相・逆位相        |
| 2物体の滑車問題              | 張力、糸の長さ・速度・加速度の関係     |

各プリセットの初期条件は編集できます。2質点系の固有モードボタンは、計算した平衡位置から固有ベクトルの比率で変位を設定します。質量が異なる場合も、質量で重み付けした固有値問題を解きます。平衡点が一意に定まらない非連結系などでは、モードの初期条件設定を無効にします。

### 自由物体図と式の導出

物体をクリックすると、その物体の重力・抗力・摩擦・ばね力・張力・外力を取り出して表示します。力の一覧には成分と単位を表示し、一覧の力を選ぶと同じ接続の対を強調します。「系全体を選択」では、動く物体間の作用反作用を破線で区別します。水平成分を持つ力だけに絞り、共通倍率を再調整する表示もあります。

固定壁や床からの力は、動く物体だけを系としたときの外力です。滑車の張力は2物体で同じ大きさでも、Cartesian方向が異なるため一般にベクトルとして相殺しません。経路座標の連立方程式から消去することと、ベクトル和の相殺を区別しています。

「式の導出を見る」で、自由物体図 → 各物体の式 → 連立式・拘束条件 → 系全体の式へ段階的に進みます。物体別の位置・速度・加速度、重心位置・加速度、エネルギー、全運動量も確認できます。グラフは物体別・物理量別に切り替えられ、未来の予測も含みます。

### 対応範囲と停止条件

このエディタは任意の剛体・接触系を解く汎用エンジンではありません。構成を検査してから、次の対応ソルバーを選択します。未対応の場合は理由を表示し、計算結果を生成しません。

| ソルバー   | 対応する構成                                      | 境界・制限                                                                             |
| ---------- | ------------------------------------------------- | -------------------------------------------------------------------------------------- |
| 自由質点   | 接続・接触形状のない質点と一定外力                | 質点間の衝突なし。単独ブロックは並進のみ。接触し得る複数ブロックの自由運動は未対応     |
| 台と物体   | 台1個と、その上の物体1個。摩擦のない床は任意で1個 | 水平運動のみ。台の端へ達する前に停止。落下・再接触は未対応                             |
| 水平ばね網 | 最大8物体、壁・支点、最大20接続。全端点が同じ高さ | 固定高さのガイド。線形ばね、接触・端点逆転前に停止。鉛直外力、摩擦、回転は未対応       |
| 固定滑車   | 2物体、固定滑車1個、糸1本。摩擦のない斜面1個まで  | 経路に平行な速度・外力のみ。多段滑車・摩擦付き斜面・ばね混在は未対応。滑車到達前に停止 |

斜面の基準点は滑車の左接線位置に合わせます。図の斜面は物体の中心経路から下へ平行移動して接触面を描きます。固定壁・支点はばねの固定端として扱い、一般の壁面衝突は扱いません。自由配置した床を追加しただけで汎用接触計算を開始することはありません。

### 数値解法と拘束

- **台**：各区間の解析解。固着時は a=(F_M+F_m)/(M+m)、上の物体に必要な摩擦は f=ma−F_m。|f|≤μₛmg を満たすか比較します。滑走時は相対速度に逆向きのμₖmgを適用し、相対速度が0になる時刻を正確に求めて再判定します。摩擦の仕事を散逸エネルギーとして集計します。
- **ばね網**：Velocity Verlet法。内部刻みは1/480秒以下、かつ剛性行列から求めた最大角振動数の上界と刻みの積を0.025以下に制限します。表示用の1/120秒とは分離しています。エネルギーには小さな有界の数値誤差があり、解析解のように誤差0とは扱いません。各内部ステップでも未対応接触を監視します。
- **滑車と糸**：qを滑車から離れる方向に取り、q₁+q₂≤L、T≥0、T(L−q₁−q₂)=0という片側拘束を使います。張っている間だけ速度和と加速度和を0とします。負の張力が必要なら拘束を解除します。たるみの解消時刻を解析的に求め、完全非弾性の拘束衝撃で速度和を0にし、運動エネルギー損失を記録します。糸の指定長は滑車の円弧の一定部分を除く直線2経路の和です。
- **グラフ**：台の摩擦切替・糸の張り直しでは、正確なイベント時刻の直前・直後を追加します。衝撃の瞬間の加速度は通常の有限値の曲線では表さず、速度の跳びと散逸量で確認します。

## 自由実験室の操作ガイドと調整

自由実験室の上部に「はじめての自由実験」を表示します。例を選ぶ → 物体をクリック → 条件を変更 → 再生、の4ステップから始められます。右上の「使い方」では、配置・接続・外力・対応構成を詳しく確認できます。ガイドはEscで閉じられ、折りたたんだ状態も保存されます。

図の上にある「操作の調整」で、ドラッグの細かさを変えられます。

| 設定         | 選べる値                             | 効果                                  |
| ------------ | ------------------------------------ | ------------------------------------- |
| 位置の移動幅 | 0.01 / 0.05 / 0.1 / 0.25 / 0.5 / 1 m | この幅ごとに移動。初期値は0.5 m       |
| 外力の変更幅 | 0.1 / 0.5 / 1 / 5 N                  | 外力の各成分を、この幅ごとに増減      |
| ドラッグ感度 | ¼ / ½ / 標準 / 2倍                   | マウスの移動に対する変更量。初期値は½ |

つかんだ位置からの移動量を丸めるため、ラベルや端をつかんでも物体の中心へ飛びません。元の位置が刻みと一致しなくても、小さな操作だけで別の位置へ変わることはありません。水平ガイドでは高さを保持し、滑車系では経路方向に移動幅を適用して糸の拘束を保ちます。ドラッグ中は反映予定の位置・外力を表示します。数値欄の矢印キーにも対応する刻みを使い、直接入力した任意の値は範囲内でそのまま設定できます。

実行できないときは、**再生ボタンのすぐ上**に理由・直し方・対象を編集するボタンを表示します。たとえば水平ばね網の高さ違いでは、合わせるyの値と該当する物体を案内します。接続操作が途中のときもその状態を示し、端点の選択完了またはキャンセルまで再生を無効にします。「選択」ツールでも接続操作を終了できます。計算の途中で対応範囲を外れる条件では、実行できる時間を事前に表示します。

矢印は力・速度・加速度ごとに切り替えられます。軌跡とグリッドも個別に表示できます。「力の種類・矢印の長さを調整」から、重力・垂直抗力・摩擦・ばね力・張力・外力などの表示、記号と大きさの表示、矢印の倍率（0.25〜2倍）を選べます。自由物体図にも力の表示設定を反映します。

**表示倍率・非表示設定は物理計算を変更しません。** 隠した力も合力と運動方程式に含まれ、倍率に応じた図の換算を明記します。外力を編集中の丸い操作ハンドルは、力を非表示にしていても表示します。操作と矢印の設定はブラウザに保存され、再読み込み後も引き継がれます。

操作改善を追加した時点の検証では、Pythonの単体テスト51件、フロントエンドの単体テスト13件、既存実験を含むChromiumの操作18ケースを確認しました。テストコードとスクリーンショットは引き続きローカル管理です。
